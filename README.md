# NovraLab — Next.js + Tailwind Starter

This starter matches your Figma screenshots and provides pages for Home, Mission, Projects, Research, and Contact, plus a small logo text reveal animation.

## Quick start

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Build

```bash
npm run build
npm run start
```

### Contact form
This template uses a mailto fallback. For production, integrate with Formspree, Netlify Functions, or your preferred backend.

### Files included
- app/ (Next.js app routes)
- components/ (React components)
- public/logo.svg
- styles/globals.css
- tailwind.config.js
